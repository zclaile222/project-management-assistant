# 工作全景表｜项目说明与文件地图

**现行版本：V3.2，2026-11-14 增补。** 本仓库只包含可部署的交付包与其源码。规则的完整变更历史保留在作者的本地项目中，不随仓库发布。

## 这是什么

使用者在助理应用里用自己的话记事、问进度或改安排。一张在线表格（飞书、钉钉、WPS 表格或离线 Excel 均可）保存事实，早间、晚间和周六的定时任务在约定时段跟进。换一台电脑时，表格不变，只重新配置本机路径。要解决的是漏催、催错时间、误把部分完成当整件结项，以及清单太长时分不出轻重。

运行宿主计划从豆包换到 DeepSeek Harness，目前还没有切换。

## 做对的标准

- 用户不用记编号、填表或选菜单。
- 系统能说清一件事为什么这次出现、下次何时再看、为什么退出。
- 提醒清单与表中应提醒的事项逐项对得上。
- 用户标的重点排在最前；暂放的事不占清单，但件数对得上，周六能逐条看到。

## 规则以哪份为准

- **业务规则**：[规则定稿 V3.2](规则定稿_20261105.md)。对业务行为有争议，以它为准。
- **运行指令**：[个人助理工作规范](实施/个人助理工作规范.md)，只引用规则，不重复业务口径。

## 不做的

- 不建独立 App、管理后台、第二套任务数据或常驻服务。
- 面板只读，不直接写表；要改单元格，在飞书表里改。
- 不单列 Web API 文档或数据库设计图；飞书原表就是任务数据源。

## 日后怎么改

改“何时提醒”或“清单怎么分层”，先改规则，再对齐公式、指令、核对工具、面板和用例。只改回话措辞，改对话样例和入口文本。只换电脑或换宿主，改本机配置，并按交付包 START-HERE 的验证步骤验证。不需要为同一处修改重写多份文档。
